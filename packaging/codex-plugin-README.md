# INKAVA Video Director

INKAVA creative direction with an adapted SeeCut execution foundation: content editing, typography, complete subtitles, B-roll, illustration, motion, deterministic rendering and review. It defaults to editing existing CapCut drafts while the application is closed, using the media imported into the project and preserving backups.

Install this plugin through a compatible plugin importer and invoke its INKAVA skill. The bundle includes adapted SeeCut helpers and third-party notices; its SeeCut software declares a noncommercial license and installation does not grant commercial rights. Runtime dependencies, service accounts, official brand assets and native CapCut compatibility remain separate. No sample videos or source frames are included. Follow the integration reference and installation guide. No public marketplace submission is made by this package.
